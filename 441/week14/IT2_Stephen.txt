Lessons Learned and Website Development Process

Key Lessons:

User Experience Matters: Simplifying navigation and ensuring intuitive interactions (e.g., replacing "Add to Cart" with "Quick Add") improved usability.

Visual Feedback is Crucial: Animations (ripple effects) and instant confirmations enhance engagement.

Consistency is Key: Maintaining a uniform color scheme (purple/blue) and layout across pages ensured professionalism.

Mobile-First Mindset: Designing for responsiveness early saved time in later adjustments.

Iterative Testing: Regular feedback loops helped refine features like the cart interface.

Development Process:

Planning: Defined goals (e-commerce for pre-owned electronics) and user flows.

Wireframing: Created layouts for homepage, product listings, and cart using Figma.

Design: Established the UI with a purple/blue theme, focusing on readability and visual hierarchy.

Development:

Built responsive HTML/CSS structure.

Implemented interactive elements (e.g., hover effects, dynamic cart updates with JavaScript).

Testing: Checked cross-browser compatibility and mobile responsiveness.

Deployment: Hosted the site, monitored performance, and gathered user feedback for updates.
